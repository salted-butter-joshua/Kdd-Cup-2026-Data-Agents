# PHASE_1 测试文档

日期：2026-09-22  
范围：KDD Cup 2026 Data Agents 公开 demo 50 题 + 交卷校验单题复核  
评测命令在 `PHASE_1/` 下执行。产物目录 `artifacts/runs/<run_id>/`。问题分析见 `复盘.md`。

打分：列内容签名匹配（忽略列名、行序）。  
`Score = max(0, 召回 − 0.1 × 多余列 / 预测列数)`。缺 `prediction.csv` 记 0，仍计入平均。

## 1. 模块

本地改的是官方 ReAct baseline，入口 `uv run dabench`。

| 模块 | 路径 | 职责 |
| --- | --- | --- |
| 配置 | `src/data_agent_baseline/config.py`、`configs/react_baseline.yaml` | 模型、并发、超时、打分系数 |
| 运行器 | `src/data_agent_baseline/run/runner.py`、`cli.py` | 单题 / 50 题并发跑，超时杀子进程 |
| ReAct Agent | `agents/react.py`、`prompt.py`、`model.py`、`runtime.py` | 调工具、交 `answer` |
| 交卷校验 | `agents/answer_check.py`（新增） | 必须全表扫描；按题目裁多余列 |
| 工具 | `tools/filesystem.py`、`registry.py`、`python_exec.py`、`sqlite.py` | `read_csv` 预览；`execute_python` 全表 |
| 打分 | `eval/scoring.py` | 对照 `data/public/output/<task>/gold.csv` |

**代码分两档：**

- **A（012037 / 072329 / 083552）**：提示词约束（精确 join、少列、并列、聚合）。交卷无强制扫描、无列交集。  
- **B（091703 / 091821）**：档 A + `answer_check`。`read_csv` 带 `truncated` / `PREVIEW ONLY`。无成功 `execute_python` 则拒收 `answer`。交卷前列名与题目推断取交集。

各轮共用 `configs/react_baseline.yaml`（密钥不入库）。

| 项 | 值 |

50 题批量：

```powershell
uv run dabench run-benchmark --config configs/react_baseline.yaml
```

```powershell

```

`read_csv` 默认 `max_rows=20`，模型可另填（如 25）。工具始终只返回前 N 行预览。
